**Kernel:**

$ \ker (A^T) = \operatorname{im} (A)^{\perp}$

If $y \in \operatorname{im} (A)^\perp$, then

$\langle Ax, y \rangle = 0 \quad \text{for all } x$

so

$\langle x, A^T y \rangle = 0 \quad \text{for all } x$

which implies $A^T y = 0$. Hence, $y \in \ker (A^T)$.

<br>

Conversely, if $y \in \ker (A^T)$, then
$\langle Ax, y \rangle = \langle x, A^T y \rangle = 0 \quad \text{for all } x$

so $y \in \operatorname{im} (A)^\perp$.
